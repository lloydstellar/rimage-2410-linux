# Everest colour tables

Lookup tables used by `rimage2410.everest.color` and `rimage2410.everest.halftone` to turn an RGB
label into the heat-energy planes the Everest 400 printer expects: 3D colour lookup tables,
screening (threshold) matrices, tone curves and heat-history parameters.

`index.json` lists each table with its size, element type and meaning. `alias_of` means that a
table name refers to another table with the same content.
